# Databasproject
# 🗄️ Database Projects

A collection of database projects developed to demonstrate practical skills in relational database design, SQL development, data modeling, and database management.

This repository contains a variety of real-world database projects, each designed to demonstrate how databases can be structured, connected, and managed efficiently using SQL and relational database concepts.

---

## 📌 Projects

### 🏥 1. Hospital Management Database

A relational database designed to manage hospital operations and organize information about patients, doctors, departments, appointments, medical records, treatments, prescriptions, medicines, rooms, and staff.

**Main Concepts:**
- Patients & Doctors
- Departments
- Appointments
- Medical Records
- Prescriptions & Medicines
- Hospital Rooms
- Staff Management
- Primary & Foreign Keys
- Database Relationships
- Normalization
